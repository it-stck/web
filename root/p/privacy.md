## 2. Personal Data Processing Overview

**ITSTCK** operates under a privacy-by-design model. Personal data collection is minimized to what is strictly required for security, optimization, and communication:

* **No Registration Forms:** `itstck.com` does not operate user accounts, membership portals, or automated comment forms.
* **Email Inquiries:** If you contact us via email, the information provided (e.g., email address, name, technical query) will be processed solely to address your inquiry.
* **Analytics:** Aggregated, anonymized site statistics are captured via Google Analytics **only if explicit consent is granted** via the site cookie banner.

---

## 3. Server Logs & Edge Telemetry

For network security, abuse prevention, and infrastructure debugging, host edge servers automatically record limited HTTP metadata in access logs:

* IP Address (anonymized where applicable)
* HTTP request time and protocol version
* Target URL requested
* Referrer URL
* User-Agent string (browser type and OS version)

**Retention Period:** Server logs are automatically purged within **30 days** and are never shared with commercial entities unless mandated by a legal order.

## 6. Your Rights Under GDPR

* Request **Access** to your personal data.
* Request **Rectification** or correction of incomplete or inaccurate data.
* Request **Erasure** ("Right to be forgotten") of personal data.
* Object to or **Restrict** processing under specified conditions.
* Request **Data Portability**.

To exercise any of these rights, contact us directly at: **[hello@itstck.com](mailto:hello@itstck.com)**.
